# ViewModel

Customize your first-person view model. Client-side Fabric mod for **Minecraft 26.3**.

## Download

**[viewmodel-26.3.jar](https://github.com/reqxdev/ViewModel/releases/download/latest-26.3/viewmodel-26.3.jar)**: latest build for Minecraft 26.3

Requires [Fabric Loader](https://fabricmc.net/use/), [Fabric API](https://modrinth.com/mod/fabric-api) and [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin).

Other Minecraft versions: switch branch, or see [all releases](https://github.com/reqxdev/ViewModel/releases).

## Usage

Press **V** in-game to open the menu.

## Building

```
./gradlew build
```
