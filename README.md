# ViewModel | MC 26.3 | Fabric

Customize your held item scale, position and swing speed.

### Requirements

- [Fabric Loader](https://fabricmc.net/use/) 0.19.5
- [Fabric API](https://modrinth.com/mod/fabric-api) 0.166.2+26.3
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) 1.14.2+kotlin.2.4.21

## Usage

Type **/viewmodel** to open the menu.

## Building

```
./gradlew build
```
